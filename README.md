## Smile Planet Farms Data Solution 
#### Project Objective
- Clean and structure the provided farm dataset (Egg Production 2022). 
- Design an improved farm data collection system using Google Forms. 
-  Integrate cleaned + newly structured data. 
- Build an insightful, executive-ready dashboard in Looker Studio. 
- Present actionable business insights for Smile Planet Farms.
